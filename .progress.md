# Graded Elasticity — Status

Branch `hypergraded`, forked from `master`. Adds hyperelasticity, graded (spatially varying)
material properties, and a latent-heat reservoir phase-change model.

Chronological detail, with the reasoning behind every decision below, is in
`.progress-log.md`. `§n` refers to its numbered sections.

---

## The one thing that governs everything else

> **No Fortran compiler exists in this environment. Not one line of this branch has ever been
> compiled or run.**

`./mfc.sh precheck` is the formatter, the linters, the doc checks and the Python tests. It
compiles nothing. Every "done" below means *written, statically checked and reasoned*, never
*executed*. Two hard compile errors survived on this branch for weeks and were found only by
building a parser to stand in for the compiler (§69).

| Verification available here | Covers |
|---|---|
| `./mfc.sh precheck` | formatting, lint, docs, parameter registry, example-case validation |

Everything in §2 is pending in this sense. These are the items where the *risk* is highest,
because the code is new and the failure mode is quiet:

| Item | Why it is risky |
|---|---|
| Latent-heat reservoir | Newton convergence and the conversion itself have never been exercised |
| Reservoir energy bookkeeping | Reasoned and simple to read, but not measured |

| Bracketed p-relax | Changes results in cells where the old solver hit its cap, which is the point — needs the suite |
| Graded profiles | Three ramp types × two projections, none run |

## 6. Deferred, with reasons

| Item | Reason |
|---|---|
| HLLD for hyperelasticity | The elastic HLLD is tied to non-conservative stress coupling that hyperelasticity does not have — its stress is slaved algebraically to the deformation gradient. It would be a new single-pass solver, not an extension. Groundwork (the transverse eigenvalue) is derived and verified. |
| pT solver onto the shared root finder | Converting it changes the stopping criterion, and therefore every phase-change golden file, for no demonstrated robustness gain. Its real defect — an unbounded step — was fixed in place with a pressure floor instead (§68). |
| pTg solver onto the shared root finder | It is a 2×2 Newton. A bracket does not exist in two dimensions. |
| `m_eos.fpp`'s three iterative loops | One is the inner loop of the p-relax solve; one is host-side init; one is a cubic that should not be iterated at all. None is a root-finder customer. |
